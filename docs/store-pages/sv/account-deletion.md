# Radera ditt Youth Card-konto

Du kan radera ditt Youth Card-konto permanent i appen eller begära radering via e-post. Raderingen kan inte ångras.

## Radera kontot i appen

1. Logga in och öppna **Mitt kort**.
2. Rulla till **Radering av konto** och välj **Radera konto**.
3. Bekräfta raderingen. När den har lyckats loggas du ut.

## Begär radering utan appen

Skicka e-post till [info@youthcard.eu](mailto:info@youthcard.eu?subject=Radering%20av%20Youth%20Card-konto) med ämnesraden **Radering av Youth Card-konto**. Ange vilken e-postadress eller vilket telefonnummer som är kopplat till kontot så att vi kan identifiera det. Begäranden som skickas via e-post hanteras manuellt. Vi kan behöva kontrollera att begäran kommer från kontoinnehavaren. Skicka inte ditt lösenord.

## Vad som raderas

När kontot raderas tas kontot och alla uppgifter som identifierar dig bort, inklusive personuppgifter som hör till kontot. Raderingen är permanent. Det går för närvarande inte att begära radering av enskilda kontouppgifter och samtidigt behålla kontot.

Statistiska uppgifter om besök vid aktiviteter finns kvar. De kan innehålla din ålder och ditt kön om du har angett dem, men är inte längre kopplade till ditt konto eller andra identifierande kontouppgifter. Det finns ingen fastställd sluttid för lagringen av dessa kvarvarande statistiska uppgifter.

Om du har frågor om radering, skriv till [info@youthcard.eu](mailto:info@youthcard.eu).
