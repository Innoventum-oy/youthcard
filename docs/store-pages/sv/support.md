# Support för Youth Card

Om du behöver hjälp med Youth Card-appen, skriv till [info@youthcard.eu](mailto:info@youthcard.eu). Vi kan hjälpa dig med åtkomst till kontot, ditt kort, aktiviteter, förmåner och tekniska problem.

Berätta vilken enhet du använder, vad du försökte göra och vilket felmeddelande du såg. Skicka inte ditt lösenord via e-post.

Om du vill radera ditt konto permanent, följ instruktionerna på sidan [Radera ditt Youth Card-konto](https://youthcard.eu/sv/account-deletion). Du kan också begära radering via e-post om du inte kan använda appen.

Information om hur appen använder uppgifter finns i [integritetspolicyn](https://youthcard.eu/sv/privacy-policy). Du kan också kontakta oss via e-post.
